# script-calculadorapython
calculadora na versão python

## Como Executar

Siga os passos abaixo para rodar o projeto no seu computador.

### 1. Pré-requisitos
* Ter o [Python](https://python.org) instalado (versão 3.10 ou superior).

### 2. Instalação
Clone este repositório e entre na pasta:
```bash
git clone https://github.com
cd script-calculadorapython
```

Crie e ative um ambiente virtual:
```bash
# No Windows
python -m venv venv
venv\Scripts\activate

# No macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

Instale as dependências:
```bash
pip install -r requirements.txt
```

### 3. Execução
Rode o arquivo principal do projeto:
```bash
python cauculadora.ipynb
```
